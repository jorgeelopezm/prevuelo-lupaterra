- [x] 2.3 Create `src/platform/weather-mcp/client.ts`: connects an MCP `Client` over `StdioClientTransport` (spawning `mcp/aviation-weather`) or `StreamableHTTPClientTransport` (per `WEATHER_MCP_TRANSPORT`), calls `callTool` for each tool, parses the JSON text result, and maps tool-level and transport-level failures (timeout, provider error, validation error, rate-limit) into the discriminated result type. While building these, found and fixed a pre-existing bug in `src/server/views/views.ts`: the `intlDate`/`intlUtc`/`intlUtcDateTime`/`intlNumber`/`intlPercent`/`translate`/`translateArray` filters read `this.context`, but Nunjucks' `Context` class exposes the render context as `.ctx`, not `.context` — every one of these filters threw `Cannot read properties of undefined (reading 'locale')` whenever actually invoked. Fixed by reading `this.ctx` throughout; `provenanceLine`/`errorBox` also take `t` and pre-formatted date strings as explicit macro parameters rather than reading them from the imported-with-context template context, since a macro imported cross-file cannot reliably read filter-dependent context either.
